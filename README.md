# AstroPixel Agency Website (astropixel.tech)

AstroPixel Agency is a 100% independent, standalone Creative Design & Development Agency website powering **astropixel.tech**.

## 🌐 Project Domain & Access Points

- **Primary Agency Website**: [https://astropixel.tech](https://astropixel.tech)
- **Agency Admin Panel**: [https://astropixel.tech/admin](https://astropixel.tech/admin)
- **Services Page**: [https://astropixel.tech/services](https://astropixel.tech/services)
- **Portfolio / Work**: [https://astropixel.tech/work](https://astropixel.tech/work)
- **About Us**: [https://astropixel.tech/about](https://astropixel.tech/about)
- **Contact Us**: [https://astropixel.tech/contact](https://astropixel.tech/contact)

---

## 🚀 Key Features

- **Creative Portfolio**: Showcase of UI/UX, branding, web development, and graphics design projects.
- **Service Listings**: Specialized agency services with inquiry forms.
- **Team Showcase**: Bento grids highlighting team members and creative talent.
- **Agency Admin Panel**: Management of portfolio items, services, team members, homepage sections, contact info, and site settings.

---

## 🛠️ Tech Stack & Setup

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons.
- **Backend & Database**: Supabase.

### Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env`:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
